# AI Builder Toolkit

A personal collection of reusable AI building blocks created while learning AI Engineering.

Instead of rewriting common AI workflows for every new project, this toolkit stores reusable templates that can be copied into future AI applications.

---

## 🎯 Purpose

This repository is part of my Healthcare AI Builder roadmap.

The goal is to build a reusable toolkit for future AI projects, including:

- Healthcare AI
- Education AI
- AI Assistants
- AI Agents

Every template is tested in a real project before being added here.

Build once.

## ▶️ How to Run (Quick Start)

## ▶️ Quick Start

```bash
pip install -r requirements.txt
```

Create a `.env` file:

```text
GEMINI_API_KEY=your_api_key_here
```

Run:

```bash
python gemini_chatbot_template.py
```
